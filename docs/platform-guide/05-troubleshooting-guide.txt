Title: Platform Troubleshooting and Incident Response Guide
Source: docs/PROJECT_CONTEXT.md

COMMON ISSUES AND SOLUTIONS

1. APIM Gateway Returns 500 Internal Server Error
   - Cause: APIM missing Host header override or backend protocol configuration.
   - Solution: Ensure APIM policy includes <set-header name="Host" exists-action="override"><value>func-ht-taxb-p-cin-01.azurewebsites.net</value></set-header> and <set-backend-service backend-id="func-backend-taxb" />.

2. Static Web App CORS Failure ("Failed to fetch")
   - Cause: Custom domain (www.mytaxbot.site) not registered in Function App CORS allowed origins.
   - Solution: Run `az functionapp cors add --name func-ht-taxb-p-cin-01 --resource-group rg-ht-taxb-p-cin-01 --allowed-origins https://www.mytaxbot.site https://mytaxbot.site "*"`

3. Section 80CCD(2) Employer NPS Calculation Mismatch
   - Cause: 14% applied to Old Regime Private sector employees.
   - Statutory Rule:
     - New Tax Regime (Section 115BAC): 14% of Basic + DA exempt for BOTH Private & Govt employees.
     - Old Tax Regime: 10% of Basic + DA exempt for Private sector employees, and 14% for Govt employees.

4. Rule 15(5)(a) Meal Card Exemption Cap
   - Statutory Rule: Up to ₹200 per meal (max ₹8,800/month, ₹1,05,600/year) 100% EXEMPT under BOTH New and Old Tax Regimes!

5. Rule 2A Metro City Exemption (HRA)
   - Statutory Rule: Metro cities strictly limited to Delhi (including NCR), Mumbai, Kolkata, Chennai (50% Basic). Bengaluru, Hyderabad, and Pune legally remain Non-Metro (40% Basic) under Income Tax Rule 2A text.

6. Terraform State Lock Error
   - Cause: A previous operation left a lock on sthtbootpcin01/tfstate/workloads/tax-advisor/prod.tfstate.
   - Solution: Run `terraform force-unlock <LOCK-ID>` or verify no background terraform apply is running.
