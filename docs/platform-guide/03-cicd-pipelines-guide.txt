PIPELINE OVERVIEW

The repository has five active Azure DevOps pipelines under pipelines/. Each pipeline maps to one Terraform root or application layer:

Pipeline File                        | Service Connection | Working Directory      | Purpose
-------------------------------------|-------------------|------------------------|---------------------------
azure-cicd-bootstrap.yml             | bootstrap         | platform/bootstrap     | Terraform state backend
azure-cicd-hub.yml                   | hub-prod          | platform/hub           | Hub VNet
azure-cicd-shared-ser.yml           | shared-services   | platform/shared-services| APIM, Log Analytics, DNS
azure-cicd-tax-advisor.yml           | app-prod          | workloads/tax-advisor  | TaxBot IaC infrastructure
azure-cicd-app-tax-advisor.yml       | app-prod          | app/tax-advisor        | React UI + Python backend

WORKLOAD IDENTITY FEDERATION (WIF)

All pipelines use Workload Identity Federation (OIDC) — no stored client secrets. The Azure DevOps service connection acts as a federated identity credential for the service principal.

Service connection setup:
- Go to Azure DevOps → Project Settings → Service connections
- Select "Azure Resource Manager" → "Workload Identity Federation (automatic)"
- Select the target subscription

TERRAFORM PIPELINE STAGES

Each Terraform pipeline (bootstrap, hub, shared-services, tax-advisor) has three stages:

  Stage 1: Validate
    - terraform init -backend-config=backend.hcl
    - terraform fmt -check -recursive
    - terraform validate

  Stage 2: Plan (runs on PRs and branch merges)
    - terraform plan -var-file=prod.tfvars -out=tfplan
    - Generates speculative plan artifact

  Stage 3: Apply (runs ONLY on merges to main/develop)
    - terraform apply tfplan
    - Requires approval in environment "production"

APPLICATION PIPELINE STAGES (azure-cicd-app-tax-advisor.yml)

  Stage 1: DeployBackend
    - Packages Python 3.11 backend (.python_packages) into functionapp.zip
    - Deploys to func-ht-taxb-p-cin-01 via zipDeploy

  Stage 2: UploadDocuments
    - Uploads 10 statutory text documents from app/tax-advisor/documents/ to sthttaxbpcin01/documents

  Stage 3: DeployFrontend
    - Fetches deployment token from Key Vault (kv-ht-ss-p-cin-01 / SWA-TAXB-DEPLOYMENT-TOKEN)
    - Builds React bundle (npm run build)
    - Deploys bundle to stapp-ht-taxb-p-cin-01 (www.mytaxbot.site)

  Stage 4: ConfigureCorsAndApim
    - Dynamically queries SWA default hostname
    - Updates Function App CORS allowed origins and APIM rate limiting security policies
