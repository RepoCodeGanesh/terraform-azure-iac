MONITORING ARCHITECTURE OVERVIEW

The Azure AI Landing Zone monitoring architecture collects telemetry across all platform layers into a single centralized Log Analytics Workspace using workspace-based Application Insights and Azure Monitor Diagnostic Settings.

TELEMETRY COMPONENTS & SUBSCRIPTION MAP

1. Central Log Analytics Workspace (`law-ht-ss-p-cin-01`):
   - Subscription: Shared-services (859a785c-bd38-402d-b595-1f44f40fb9bf)
   - Resource Group: rg-ht-ss-p-cin-01
   - SKU: PerGB2018 (Pay-as-you-go, 30-day retention)
   - Aggregates logs from APIM, Function App, OpenAI, AI Search, Cosmos DB, and Key Vault.

2. Workload Application Insights (`appi-ht-taxb-p-cin-01`):
   - Subscription: Apps-prod (f4ffefe1-d689-4059-969c-ccc73e2a11d4)
   - Resource Group: rg-ht-taxb-p-cin-01
   - Type: Workspace-based (backed by law-ht-ss-p-cin-01)
   - Captures: Python Function App traces, request latency, HTTP exception stack traces, custom telemetry events.

ESSENTIAL KQL QUERIES FOR TAXBOT INDIA

1. Function App Requests & Latency Overview:
   requests
   | where timestamp > ago(24h)
   | summarize TotalRequests = count(), AvgDurationMs = avg(duration), P95DurationMs = percentiles(duration, 95), Failures = countif(success == false) by name
   | order by TotalRequests desc

2. API Exceptions & Error Stack Traces:
   exceptions
   | where timestamp > ago(24h)
   | project timestamp, problemId, type, outerMessage, innermostMessage, operation_Name
   | order by timestamp desc

3. APIM Gateway HTTP 429 Rate Limit Throttling:
   ApiManagementGatewayLogs
   | where ResponseCode == 429
   | summarize ThrottledRequests = count() by ClientTime, CallerIpAddress, ApiId
   | order by ClientTime desc

4. OpenAI Model Token Usage & Latency Tracking:
   AzureDiagnostics
   | where ResourceType == "COGNITIVESERVICES"
   | summarize TotalTokens = sum(toint(properties_s.total_tokens)), Requests = count() by Resource, Model_s = tostring(properties_s.model)

AZURE MONITOR METRIC ALERTS SETUP

1. Function App Server Errors (HTTP 5xx Alert):
   - Scope: func-ht-taxb-p-cin-01
   - Metric: Http5xx (Server Errors)
   - Threshold: Count > 0 over 5-minute window
   - Action: Send Email / Webhook notification

2. APIM Rate Limit Alert (HTTP 429 Alert):
   - Scope: apim-ht-ss-p-cin-01
   - Metric: Gateway Requests (Filtered by 429 response)
   - Threshold: Count > 5 over 5-minute window
