# BankCompliance AI — Frontend SPA

Production React SPA for the RBI Regulatory & Legal Copilot, deployed on Azure Static Web Apps (`stapp-ht-bankc-p-cin-01`) at [https://bank.mytaxbot.site](https://bank.mytaxbot.site).

## Architecture & Features
- **Modern Clean Workspace:** Decluttered interface focused on high-impact learning and executive clarity.
- **Deep Architecture Inspector Modal:** Five dedicated tabs explaining Architecture Topology, GraphRAG Mesh, Multi-Agent StateGraph, Cloud Cost Breakdown ($0.00 idle), and Production Verification Attestation.
- **Real-Time Regulatory Intelligence:** Real-time query streaming and citation verification against 13+ RBI Master Directions.
